🛠️ Easy Installation

1

Copy Files to Your ULTRON Directory

Place all web dashboard files in your existing ULTRON Agent root directory.

cp ultron-web-dashboard.html /your/ultron/directory/
2

Install Dependencies

Install the required Python packages for the web server.

pip install fastapi uvicorn websockets aiohttp psutil
3

Launch the Dashboard

Start the web server and access your dashboard in any browser.

python launch_ultron_web.py
4

Access Your Dashboard

Open your browser and navigate to the dashboard URL.

http://localhost:8000
